# Vietri DS

A themeable Design System built with React, TypeScript and MUI.

## Goals

- Reusable, composable components
- Design tokens
- Multi-theme architecture
- Storybook documentation
- Testing
- Responsive and accessible UI

## Themes

- Editorial — the base Soraya visual language
- Streaming — for the streaming application
- Observatory — for the data/cultural platform

## Stack

React · TypeScript · MUI · Vite · Storybook · Vitest · Testing Library
